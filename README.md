# 전문역량 메타인지

HR 혁신 요구사항 RQ-0024~0027 및 전문역량평가 화면설계를 반영한 정적 HTML 대시보드입니다.

화면에 표시되는 인사정보와 평가값은 모두 공개 데모용 샘플 데이터입니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버가 필요하면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 4173
```

## 구현 범위

- 직원 본인의 현재/차년도 예측 역량 Level과 산출 근거
- 역량·성과·보유기술·근무현황·종합지표 탭
- 다면역량진단 영역별 본인/조직 평균 비교
- 자격증·교육 이력과 직무 필수요건 Gap
- 부서장용 조직·직급·직무 필터와 구성원 비교
- 관심 직원 등록/해제 및 CSV 다운로드
- 반응형 레이아웃과 라이트/다크 테마

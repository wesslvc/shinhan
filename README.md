# SHINHAN DS 전문역량 메타인지

SHINHAN DS e-HR 전문역량 메타인지 화면의 정적 HTML 데모입니다. 화면의 인사정보와 평가값은 모두 공개 데모용 샘플 데이터입니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 열면 됩니다. 로컬 서버가 필요하면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 4173
```

## 파일

- `index.html`: Claude Design 화면 템플릿과 상태·이벤트 로직
- `support.js`: `sc-if`, `sc-for`, 데이터 바인딩 및 이벤트를 일반 브라우저에서 실행하는 경량 런타임

## 구현 기능

- 개인·조직 전문역량 메타인지 대시보드
- 역량 Level 조회와 조직 필터
- 직무 정의서 등록·수정·삭제
- 다면역량진단 입력·제출
- 기술역량평가 설정과 결과 파일 연동
- 평가 가중치 재계산과 결과 조회
- 교육·자격 추천 및 성장 계획
- CSV 내보내기, 모달, 반응형 모바일 레이아웃

데모 상태는 브라우저 세션에서만 유지되며 새로고침하면 초기 샘플로 복원됩니다.
